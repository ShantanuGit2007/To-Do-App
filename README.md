# 📋 To-Do App

A simple and interactive To-Do List web application built using **Streamlit**.  
This app allows users to add, update, and delete tasks easily with a clean UI.

---

## 🚀 Features

- ➕ Add new tasks
- ✏️ Modify existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks using checkboxes
- 📅 Clean and responsive layout
- 💾 Session-based task storage using `st.session_state`
